# 账号管理接口接入

GET /sys-user/page?pageNum=1&pageSize=10，响应 ResponseVO.data 为 PageResult<SysUserMsgVO>，使用 records、totalCount、total（总页数）。请求带 Bearer Token，复用 managementRequest，403 提示无权限但保留会话。

页面提供分页、每页10/20/50条、本页姓名与账号搜索、类型/状态/辅导员绑定筛选、只读详情。详情来自列表快照，未假设存在单账号详情接口。只保留 VO 的展示字段，不保留密码或密码算法。教职工类型不代表已分配具体RBAC角色。

未接入的功能：指定账号绑定/解绑辅导员、角色分配、编辑或禁用他人账号。目前 Controller 未提供这些管理接口。updateInfo 和 delete 针对当前登录账号，不能用于列表行操作。原静态绑定演示已从页面移除。

沿用现有蓝白管理端设计，桌面表格，700px以下纵向列表和单列详情。

验证：生产构建、账号字段白名单及筛选单元测试；模拟接口浏览器检查403重试、分页、搜索、只读详情、375px布局。未写入真实数据库。
