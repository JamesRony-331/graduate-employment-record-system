# 班级与学院管理

## 统一设计

沿用管理端现有体系：主色 #244c8b，正文 #202c40，辅助文字 #58667c，背景 #f4f6fa，分隔线 #e1e6ee；字体使用 PingFang SC / Microsoft YaHei。内容左对齐，标题 28px，区块标题 19px。主工作区为表格，不增加装饰性统计卡片。700px 以下转换为纵向列表与单列表单，操作按钮最小高度 44px。

frontend-design 指导层级、配色与布局；frontend-skill 指导克制的信息组织和实现；ui-ux-pro-max 用于表单、反馈、键盘及响应式检查。优先保留现有 Vue3 + Element Plus 架构。

两页复用 OrganizationManagement 组件，通过 organizationContracts 中的字段定义区分业务。详情和编辑均调用详情接口获取最新资料；详情为只读。保存失败保留输入，离开未保存表单需确认。加载、无数据、查询失败分别显示；403 不清除会话，401 跳转登录。

## 对接

学院：GET /college/page、GET /college/{id}、POST /college/add、PUT /college/update、DELETE /college/{id}。
班级：GET /class/page、GET /class/{id}、POST /class/add、PUT /class/update、DELETE /class/{id}；独立绑定使用 PUT /class/bind-college。
分页使用 pageNum / pageSize，解析 records、totalCount、total（总页数）。搜索明确为本页筛选，后端暂无搜索参数。
学院下拉按每页100条遍历已有分页接口，不仅加载首页。列表显示学院名称，加载失败保留ID并提供重试，不能通过未加载完整的选择器提交。
字段长度和数值范围按 DTO 校验。已有入学年份暂不允许清空，因为 ClassMapper 的 update 忽略 null；新增可留空。学生人数是接口存储字段，不描述为实时统计。
删除是物理删除，需确认；关联数据限制使用后端错误提示。

## 需要后端调整（本次未修改）

SecurityConfig 当前未授权 /class/** 与 /college/**，会被 anyRequest().denyAll() 拒绝。
需要在 STAFF 规则中增加这两个路径，或在 denyAll 之前添加：

```java
.requestMatchers("/class/**", "/college/**").hasRole("STAFF")
```
