# 管理端页面设计与接入

统一设计：深蓝 #17345d 侧栏，主操作色 #244c8b，浅灰 #f4f6fa 工作区，白色内容区，正文 #202c40，次要文字 #58667c。沿用学生端 PingFang SC / Microsoft YaHei 字体，标题28px、分区19px、正文14px。工作台以业务入口与备案流程为核心，不展示虚构的统计和待办数。移动端导航折叠、表单双列转单列；按钮、输入框至少44px，提供键盘焦点、错误汇总、减少动态效果适配。

- 登录：POST /sys-user/login，发送 username/password/accountType=STAFF，接收 token 和 userMsgVO。
- 个人资料：来自登录返回值，暂无独立查询接口。
- 修改：PUT /sys-user/updateInfo，仅提交变更的 realName、password。登录账号只读，不发送 username；修改密码后重新登录；counselorId 只读。
- 不区分老师和管理员角色，不根据关联ID推断权限。
- 工作台业务入口为占位，学生管理、审核、通知、服务管理和统计尚未接入。
- 不开放自行注册或删除账号入口；未修改后端代码。
- 管理端会话使用独立 sessionStorage key，白名单保存账号信息，不保存密码。
- 开发服务默认5176端口，/api代理至127.0.0.1:5050。

缺失接口：当前账号资料查询、角色及权限查询、待办与统计接口，以及各管理业务接口。个人资料更新时间仅显示登录时记录，不伪造服务器更新时间。

## 账号与辅导员静态管理

新增 /accounts 和 /counselors 菜单及页面。所有列表为标注的示例数据，绑定、更换和解绑只更新内存，不请求后端，不持久化。辅导员名单展示与账号绑定预览联动，刷新恢复默认示例。沿用 sys_user.counselor_id 一对一关联，禁止重复绑定其他账号已占用的辅导员。角色及账号角色绑定 SQL 位于后端 sql/sys_rbac.sql，未执行，不自动分配管理员角色。

统一账号改造后，账号资料不再允许修改 username 或 counselorId；角色与辅导员管理页面仍维持静态演示。数据库切换步骤见后端 docs/统一账号迁移说明.md。
